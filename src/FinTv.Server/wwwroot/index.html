AI Lineup Generator

AI lineup generation is disabled. Configure API keys below, then enable the switch to generate lineups.

Test Connection works before enabling AI. Enter an API key, pick the matching provider, then test. Save settings after a successful test.

Provider settings

AI lineups build up to 14 days of playout. FinTV auto-extends the schedule as each day ends. Auto-apply sets content mix and playout template from channel rules, generates the lineup, and rebuilds playout. The scheduled task adds one day when the horizon drops to 13 days instead of rebuilding all 14. Queued new channels can also be processed from Dashboard → Scheduled Tasks → FinTV AI Lineup Auto-Apply (Channel Add).

Weather guide metadata

When AI is enabled, FinTV generates TV-guide-style titles and descriptions for each weather channel location and hour of day (0–23). Generation runs once when you click Generate Weather Guide Cache, then the same metadata is reused every day for matching time slots. EPG and playout builds read the cache only — they do not call the LLM.

Channel auto-tagging

FinTV can write fintv-* tags onto movies, series, and music videos using the same channel rules used for AI lineups. When enabled, AI catalog loading queries those tags first so Generate All is much faster on large libraries. Run once before your first Generate All, or enable the weekly scheduled task to pick up new media automatically.
